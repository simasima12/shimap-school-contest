# 島ップ

離島の住まいと暮らしを探すWebアプリです。島の特徴、地図、賃貸物件情報を確認し、島診断から自分に近い暮らし方を考えられます。

## 起動方法

初回だけ、このフォルダで `npm install` を実行します。その後は `start.cmd` をダブルクリックしてください。表示されたURLをブラウザで開きます。

終了するときは、起動した黒い画面で `Ctrl+C` を押すか、その画面を閉じます。終了後にバックグラウンド処理は残りません。

## 作品の構成

- 表示名: 島ップ
- `app/property-data.json` に収録した物件データを読み取る
- 地図を表示するときだけ、国土地理院から地図画像を読み込む
- 物件元リンクを開いた場合は、ブラウザから外部サイトへ移動する

## データの注意

物件データは収録時点の情報であり、自動更新されません。現在の募集状況や条件は、必ず掲載元で確認してください。

## 確認

`npm run verify` で個人情報検査、lint、型チェック、ビルドをまとめて実行できます。
